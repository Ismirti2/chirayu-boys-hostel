# 🏢 Chirayu Boys Hostel - Modern Management Website

A complete, modern, and fully functional website for Chirayu Boys Hostel built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, and shadcn/ui.

## 🎯 Features

### Public Website
- ✅ Animated Hero Section with "Admission Open 2026"
- ✅ Facilities Showcase (Rooms, Food, Wi-Fi, Laundry, Security)
- ✅ Room Types Display (1, 2, 3 Seater)
- ✅ Weekly Menu Section
- ✅ Nearby Colleges Information
- ✅ Location Details
- ✅ Floating Enquire Now Button

### Enquiry System
- ✅ Beautiful Modal Form
- ✅ WhatsApp Integration (9804396180)
- ✅ Email Simulation (chirayuboyshostel@gmail.com)
- ✅ Form Validation

### Student Portal
- ✅ Login with Unique Student ID (e.g., CH-2026-001)
- ✅ Dashboard with Profile
- ✅ Room Details
- ✅ Notices Management
- ✅ Messaging to Admin
- ✅ Notifications
- ✅ Complaints System
- ✅ Attendance Tracking (In/Out)
- ✅ Weekly Menu Access

### Admin Panel
- ✅ Admin Login (admin / chirayu123)
- ✅ Dashboard with Statistics
- ✅ Student Management (Add, Edit, Generate ID)
- ✅ Room Management

- ✅ Settings

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Components**: shadcn/ui
- **State Management**: Zustand
- **Icons**: Lucide React
- **Storage**: localStorage (for demo persistence)

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Ismirti2/chirayu-boys-hostel.git

# Navigate to project
cd chirayu-boys-hostel

# Install dependencies
npm install

# Run development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)
